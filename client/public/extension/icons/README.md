# WishKeeper Extension Icons

This directory contains the icon assets for the WishKeeper browser extension in various sizes.

## Icon Sizes

The extension requires icons in multiple sizes to ensure proper display across different browser contexts:

- `icon16.png` (16×16px) - Used in the extension management page
- `icon32.png` (32×32px) - Used in Windows taskbar 
- `icon48.png` (48×48px) - Used in the extension toolbar
- `icon128.png` (128×128px) - Used in the Chrome Web Store and installation dialog

## Design Guidelines

All icons follow these design principles:

- Clean, simple design that's recognizable at small sizes
- Consistent brand colors (primary: #4f46e5, accent: #10b981)
- Rounded corners with a slight drop shadow
- Transparent background

## Usage Requirements

When distributing the extension, all icon sizes must be included to ensure proper display across all platforms and contexts.

## Generating Additional Sizes

If you need to generate additional icon sizes, use the provided source file (`icon-source.svg`) and export to the desired dimensions, ensuring proper optimization for web usage.
